# Simulasi Remunerasi RS (React + Vite)

Aplikasi frontend-only untuk simulasi remunerasi rumah sakit dengan penyimpanan `localStorage`.

## Menjalankan
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Deploy ke Vercel
1. Push repo ke GitHub.
2. Import project di Vercel.
3. Framework preset: **Vite**.
4. Build command: `npm run build`.
5. Output directory: `dist`.
6. Deploy.

## Struktur folder
- `src/components`
- `src/layouts`
- `src/pages`
- `src/hooks`
- `src/utils`
- `src/data`
- `src/context`
- `src/routes`

## Modul
Dashboard, Input RS, Simulasi Pegawai, IKI & IKU, Job Value, Rekap, Sumber Acuan, Pengaturan.
